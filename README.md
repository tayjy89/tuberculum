# Tuberculum

Educator review edition of an interactive TB course for Singapore general practitioners.

Nine teaching experiences, nine patient journeys and a 30-decision final assessment. Open index.html or serve the repository as a static site. GitHub Pages publishes main from the repository root.

Progress is saved in the current browser only. Videos are recording placeholders. Assessment results are for review; certificate issuance and central learner records are not implemented. Clinical and assessment validation remain in progress.
